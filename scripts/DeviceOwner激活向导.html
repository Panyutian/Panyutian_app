① 手机端准备（按顺序勾选）

✓
开启开发者选项必须

设置 → 关于手机 → 连续点击「版本号」7次

✓
开启「USB调试」和「USB安装」必须

设置 → 系统和更新 → 开发人员选项：
☑ USB调试    ☑ 「USB安装」（允许通过USB安装应用）
☐ 取消勾选「通过 USB 验证应用」（避免安装拦截）

✓
移除所有 Google 账号失败率No.1

设置 → 用户和账号 → 找到所有 Google / Gmail 账号 → 点击「删除账号」
⚠️ 激活后可以重新登录。不删除大概率会报错「accounts on the device」

✓
关闭隐私空间 / 多用户 / 访客必须

设置 → 隐私 → 隐私空间（点进去→删除）
设置 → 用户和账号 → 当前用户：确保没有「访客」「子用户」
⚠️ 否则会报错：already several users on the device

✓
数据线连接电脑，选择「传输文件(MTP)」必须

插入USB后，下拉通知栏 → 「USB用途」/「USB连接方式」→ 选择「传输文件(MTP)」
❌ 不要选「仅充电」「MIDI」

✓
允许USB调试弹窗必须

手机屏幕弹出「允许USB调试吗？」 → ☑ 始终允许此计算机 → 点「允许」
若没弹：拔插数据线、撤销USB调试授权后重新拔插

✓
安装 APK必须

把 app-release.apk 安装到手机（文件管理器点击安装，或 Android Studio Run）
安装完成后先不要打开，激活DeviceOwner后再开。

✓
安装荣耀手机驱动（可选，识别不到设备时）可选

在「此电脑」右键→管理→设备管理器：若有黄色感叹号的 Android/荣耀设备 → 安装荣耀手机驱动
下载地址：华为手机助手 Hisuite 自带驱动 https://consumer.huawei.com/cn/support/hisuite/

② 执行激活命令

💡 推荐方式：直接双击运行 scripts\01_激活DeviceOwner.bat （或右键以管理员运行 scripts\以管理员身份激活DeviceOwner.bat）， 脚本会自动完成以下 ADB 步骤，并有错误提示。

手动执行方式（复制每条命令到 CMD / PowerShell 运行）

点击命令右上角「复制」按钮，然后粘贴到命令行。

步骤 1：重启 ADB 服务

adb kill-server
adb start-server复制

步骤 2：确认设备连接

adb devices复制

输出示例：XXXXXXXXX device（device代表正常，unauthorized需授权，offline需重连）

步骤 3：查看手机信息（可选）

adb shell getprop ro.product.brand
adb shell getprop ro.product.model
adb shell pm list users复制

步骤 4：确认 APK 已安装

adb shell pm list packages com.honor.appblocker复制

应输出 package:com.honor.appblocker，没有的话请先安装 APK。

🔥 步骤 5：核心命令 — 激活 DeviceOwner

⚠️ 此命令是整个流程的核心。成功后输出 Success: Device owner set to package ...
adb shell dpm set-device-owner com.honor.appblocker/.AdminReceiver复制

步骤 6：验证激活成功

adb shell dumpsys device_policy | findstr /i "Device Owner: disallow_install_apps"复制

③ 常见错误与解决

点击下方问题展开解决方案：

▼
❌ Not allowed to set the device owner because there are already several users on the device
原因：设备上有多个用户 / 访客 / 隐私空间
解决：
1. 设置 → 隐私 → 隐私空间 → 点击右上角「删除」
2. 设置 → 用户和账号 → 当前用户 → 除了主用户「机主」，其他全部删除
3. 重跑命令，若仍失败，必须：备份数据 → 恢复出厂设置 → 开机时不要连WiFi / 不要登录任何账号 → 不完成向导，直接紧急呼叫拨号盘拨号 *#*#7780#*#* 或 进入开发者选项开USB调试 → 电脑连上立即执行激活命令。
▼
❌ Not allowed to set the device owner because there are already some accounts on the device
原因：存在 Google / Gmail / 企业账号
解决：设置 → 用户和账号 → 找到所有 Google / Gmail / Outlook / 公司 账号 → 点「删除账号」。
如果看不到账号但仍报错：设置 → 应用 → 右上角 → 显示系统进程 → Google Play 服务 → 存储 → 清空缓存 + 清空数据，重启手机后重试。
▼
❌ Neither user 2000 nor current process has android.permission.BIND_DEVICE_ADMIN
原因：Android 14+ 和高版本荣耀 Magic UI 6+ 新增了安全限制：已完成开机向导（已Provisioned）的设备，普通ADB无法设DeviceOwner。
解决（二选一）：
方法A - 恢复出厂 + 向导前激活（成功率100%）：
1. 备份所有数据 → 设置 → 系统和更新 → 重置 → 恢复出厂设置
2. 开机进入欢迎页（语言选择页），此时不要连WiFi，跳过所有可跳过的选项
3. 在语言页/紧急呼叫页，连按版本号（或紧急呼叫拨打*#06#，再进开发者模式各ROM不一样） → 实在进不去就完成向导但全程不登录任何账号，然后立即开开发者选项→USB调试→立即运行本脚本。越早运行，成功率越高。
方法B - 扫码零接触配置：开机向导第一页（欢迎），在屏幕任意区域连续点击6次进入扫码模式，生成DeviceOwner二维码进行扫码配置。
▼
❌ unknown admin: ComponentInfo{...AdminReceiver} / No active admin
原因：① APK没装成功；② APK旧版本装了但是接收器没声明；③ 包名/接收器名写反了
解决：
1. 确认已装：adb shell pm list packages com.honor.appblocker 必须有输出
2. 没装的话：adb install -r app-release.apk
3. 如果手机上有旧版，先卸载旧版再重新安装：adb uninstall com.honor.appblocker
▼
❌ 'adb' 不是内部或外部命令，也不是可运行的程序
原因：电脑没装ADB工具，或未加入系统 PATH
解决：
1. 下载平台工具：点此下载
2. 解压到 C:\adb（或任意目录）
3. Windows开始菜单搜索「环境变量」→ 编辑「Path」→ 新建 → 粘贴 C:\adb（platform-tools完整路径）
4. 关闭所有CMD窗口，重新打开再试。
▼
❌ adb devices 输出 unauthorized / 空列表 / offline
unauthorized：没点手机上的「允许USB调试」弹窗。解锁手机，弹窗点允许。若没弹：开发者选项→「撤销USB调试授权」→ 重启ADB→重插数据线。
空列表：① 换数据线（一定要是带数据的线）；② USB用途选传输文件(MTP)；③ 装荣耀驱动；④ 换USB口（台式机推荐后面的USB口）。
offline：ADB进程异常，运行 adb kill-server & adb start-server 并重新拔插数据线。
▼
❌ adb install 失败：INSTALL_FAILED_VERIFICATION_FAILURE 或 荣耀提示"风险应用拦截"
原因：荣耀安全中心（手机管家）拦截了 USB 安装的未知来源应用
解决：
1. 开发者选项中：关闭「通过 USB 验证应用」「USB安装验证」「应用安装验证」
2. 手机端若弹窗提示「风险应用」「请输入华为账号密码验证」→ 点「继续安装」或「忽略风险」
3. 若仍不行：直接把APK复制到手机存储 → 文件管理器点击手动安装 → 允许「未知来源应用」

④ 解除 DeviceOwner（需要卸载APP时）

DeviceOwner 模式下无法直接在设置里卸载APP，必须先解除。
REM 方式1：优先尝试清除DeviceOwner
adb shell dpm clear-device-owner com.honor.appblocker

REM 方式2：移除管理员权限
adb shell dpm remove-active-admin com.honor.appblocker/.AdminReceiver

REM 之后就可以卸载了
adb uninstall com.honor.appblocker复制
